# Налаштування SMS нагадувань через Twilio

## Переваги SMS нагадувань

✅ **Працює без Telegram** - клієнту не потрібно встановлювати додатки
✅ **100% доставка** - SMS отримає кожен, хто має телефон
✅ **Автоматичні нагадування** - по номеру телефону без додаткових даних
✅ **Простота для клієнта** - просто вказати номер телефону при записі

## Крок 1: Реєстрація в Twilio

1. Перейдіть на https://www.twilio.com/try-twilio
2. Зареєструйтеся (безкоштовний тестовий акаунт)
3. Підтвердіть email та телефон
4. Отримаєте **$15 безкоштовних кредитів** для тестування

## Крок 2: Отримання облікових даних

### Account SID та Auth Token

1. Після входу перейдіть в Dashboard
2. Знайдіть секцію "Account Info"
3. Скопіюйте:
   - **Account SID** (починається з AC...)
   - **Auth Token** (натисніть "Show" щоб побачити)

### Отримання телефонного номера

1. В меню зліва оберіть **Phone Numbers** → **Manage** → **Buy a number**
2. Для України:
   - Оберіть країну: **Ukraine (+380)**
   - Натисніть **Search**
   - Оберіть номер з можливістю SMS
3. Натисніть **Buy** (витратить ~$1 з ваших кредитів)
4. Номер буде у форматі: **+380XXXXXXXXX**

**Важливо для тестового акаунту:**
- Ви можете відправляти SMS тільки на **верифіковані номери**
- Щоб верифікувати номер: Phone Numbers → Verified Caller IDs → Add new number
- В production акаунті обмежень немає

## Крок 3: Налаштування в проекті

Додайте дані в `.env` файл:

```env
# Twilio SMS Configuration
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=your_auth_token_here
TWILIO_PHONE_NUMBER=+380XXXXXXXXX
```

**Важливо:**
- Не додавайте пробіли до/після значень
- `TWILIO_PHONE_NUMBER` повинен бути в міжнародному форматі з +

## Крок 4: Перезапуск backend

```bash
sudo supervisorctl restart backend
```

## Крок 5: Тестування

### Ручне тестування через Python

```python
cd /app/backend
python3 -c "
import asyncio
from sms_service import sms_service

async def test():
    result = await sms_service.send_sms(
        '+380XXXXXXXXX',  # ваш номер
        'Тест SMS з Nail Studio!'
    )
    print('Відправлено!' if result else 'Помилка!')

asyncio.run(test())
"
```

### Тестування через запис

1. Створіть новий запис на сайті
2. **НЕ вказуйте** Telegram ID
3. Просто вкажіть номер телефону
4. Після підтвердження адміном ви отримаєте SMS

### Тестування нагадувань

```bash

```

Перевірте логи:

## Автоматична відправка нагадувань

### Налаштування Cron (рекомендовано)

Відкрийте crontab:
```bash
crontab -e
```

Додайте задачу (перевіряти кожні 15 хвилин):
```cron
*/15 * * * * cd /app/backend && /usr/bin/python3 send_reminders.py >> /var/log/reminders.log 2>&1
```

Для перевірки кожні 5 хвилин (активніше):
```cron
*/5 * * * * cd /app/backend && /usr/bin/python3 send_reminders.py >> /var/log/reminders.log 2>&1
```

### Перевірка що cron працює

```bash
# Перевірити список задач
crontab -l

# Перевірити логи cron
grep CRON /var/log/syslog

# Перевірити логи нагадувань
tail -f /var/log/reminders.log
```

## Логіка роботи нагадувань

### Коли відправляються

Нагадування відправляється **один раз** коли:
- Настав час нагадування (запис - X годин)
- Запис має статус "confirmed" або "pending"
- Нагадування ще не було відправлено

### Пріоритет відправки

1. **Спочатку Telegram** (якщо вказано Telegram ID)
2. **Потім SMS** (якщо немає Telegram ID або Telegram не вдалося)

### Приклад розкладу

Запис на **15 січня о 14:00**, нагадати за **24 години**:
- Нагадування відправиться **14 січня о 14:00** (або після, при першому запуску cron)

Запис на **15 січня о 10:00**, нагадати за **2 години**:
- Нагадування відправиться **15 січня о 8:00**

## Вартість

### Тестовий акаунт
- 💰 **$15 безкоштовно** при реєстрації
- 📱 SMS в Україну: **~$0.05** за повідомлення
- ⏱ Це приблизно **300 SMS безкоштовно**

### Production акаунт
- 📱 SMS в Україну: **$0.045 - $0.075** за SMS
- 💳 Щомісячна абонплата за номер: **$1.15**
- 📊 При 100 SMS на місяць: **~$6-8 на місяць**

### Економія
Комбінуйте Telegram + SMS:
- Telegram нагадування - **безкоштовно**
- SMS тільки для тих, хто не має Telegram
- Типово 30-40% клієнтів використовують Telegram → економія 30-40%

## Troubleshooting

### SMS не приходять

1. **Перевірте баланс** в Twilio Console
2. **Перевірте логи**:
   ```bash
   tail -f /var/log/supervisor/backend.err.log
   ```
3. **Перевірте формат номера**: повинен бути +380XXXXXXXXX
4. **Тестовий акаунт**: переконайтеся що номер верифіковано

### "Unable to create record: The number +380... is unverified"

Це тестовий акаунт Twilio. Рішення:
1. Верифікуйте номер: Console → Phone Numbers → Verified Caller IDs
2. АБО оновіться до paid акаунту (додайте кредитну карту)

### Cron не запускається

```bash
# Перевірити чи працює cron
sudo systemctl status cron

# Якщо не працює - запустити
sudo systemctl start cron
sudo systemctl enable cron

# Перевірити синтаксис crontab
crontab -l

# Тестовий запуск
cd /app/backend && python3 send_reminders.py
```

### Повідомлення відправляються кілька разів

Переконайтеся що поле `reminder_sent` правильно оновлюється в MongoDB:
```bash
# Перевірити через mongosh
mongosh
use nail_salon
db.bookings.find({reminder_sent: true})
```
