# 💅 Nail Studio - Multi-Master Booking System

Система онлайн-бронювання для салону краси з підтримкою кількох майстрів, персональними графіками та ізоляцією даних.

## ✨ Особливості

- 🎯 **Multi-Master Архітектура** - кожен майстер управляє своїми клієнтами та графіком
- 📅 **Бронювання на 6 місяців вперед** - з автоматичною перевіркою доступності
- ⏰ **Гнучкий графік** - кожен майстер налаштовує свій робочий час
- 🏖️ **Планування відпусток** - автоматична блокування слотів
- 👥 **CRM система** - база клієнтів з історією відвідувань
- 🔐 **Role-Based Access** - окремі панелі для адміна та майстрів
- 📱 **Responsive Design** - працює на всіх пристроях
- 🇺🇦 **Повна українізація** - інтерфейс українською мовою

## 🛠️ Технології

### Backend
- **FastAPI** - швидкий асинхронний API фреймворк
- **MongoDB** - NoSQL база даних
- **Motor** - асинхронний MongoDB драйвер
- **JWT** - автентифікація
- **Pydantic** - валідація даних

### Frontend
- **React** - UI бібліотека
- **React Router** - роутинг
- **Tailwind CSS** - стилізація
- **Shadcn UI** - компоненти
- **Axios** - HTTP клієнт
- **Sonner** - сповіщення

## 📦 Швидкий Старт

### 1. Клонування та налаштування

```bash
# Клонувати репозиторій
git clone <repo-url>
cd nail-studio

# Backend
cd backend
cp .env.example .env
# Відредагуйте .env файл

# Frontend
cd ../frontend
cp .env.example .env
# Відредагуйте .env файл
```

### 2. Ініціалізація бази даних

```bash
cd backend
python3 init_db.py
```

**Створені тестові акаунти:**
- 👤 Майстер 1: `olena@example.com` / `master123`
- 👤 Майстер 2: `maria@example.com` / `master123`
- 👨‍💼 Адміністратор: `admin` / `admin123`

### 3. Запуск (на платформі Emergent)

Сервіси запускаються автоматично через supervisor:
- Backend: `http://localhost:8001`
- Frontend: `http://localhost:3000`

## 🎯 Основні Функції

### Для Клієнтів
- 🔍 Вибір майстра зі списку
- 💅 Перегляд послуг кожного майстра
- 📆 Вибір дати та часу з доступних слотів
- ✅ Підтвердження бронювання

### Для Майстрів
- 📊 Особистий дашборд з статистикою
- 📅 Управління записами (підтвердження, скасування)
- 👥 База клієнтів з історією
- 💼 Управління послугами та цінами
- ⏰ Налаштування графіку роботи
- 🏖️ Планування відпусток

### Для Адміністратора
- 👨‍💼 Управління майстрами
- ⚙️ Налаштування системи
