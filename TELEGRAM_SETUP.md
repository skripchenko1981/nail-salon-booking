# Налаштування Telegram бота для нагадувань

## Крок 1: Створення бота

1. Відкрийте Telegram та знайдіть **@BotFather**
2. Відправте команду `/newbot`
3. Введіть ім'я для вашого бота (наприклад: "Nail Studio Bot")
4. Введіть username для бота (повинен закінчуватись на `bot`, наприклад: `nailstudio_booking_bot`)
5. BotFather надасть вам **токен бота** - зберіжіть його!

Приклад токену: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`

## Крок 2: Налаштування токену в .env

Додайте токен бота у файл `.env`:

```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
```

## Крок 3: Отримання Telegram ID клієнта

Є декілька способів отримати Telegram ID:

### Спосіб 1: Через бота @userinfobot
1. Клієнт відкриває Telegram
2. Шукає бота **@userinfobot**
3. Натискає Start
4. Бот відправить ID - це те, що потрібно вказувати при записі

### Спосіб 2: Через @getmyid_bot
1. Клієнт шукає **@getmyid_bot**
2. Натискає Start
3. Отримує свій ID

### Спосіб 3: Через username (рекомендовано для простоти)
Клієнт може просто вказати свій **@username** при записі, і бот зможе надіслати йому повідомлення.

## Крок 4: Тестування

### Перезапустіть backend з новим токеном:
```bash
sudo supervisorctl restart backend
```

### Створіть тестовий запис:
1. Перейдіть на сайт
2. Оберіть послугу, дату та час
3. Заповніть контактні дані
4. **Важливо**: Вкажіть ваш Telegram ID або @username в полі "Telegram ID"
5. Створіть запис

### Перевірка повідомлень:
Ви повинні отримати повідомлення в Telegram про:
- ✅ Очікування підтвердження запису

Коли адміністратор підтвердить запис:
- ✅ Підтвердження запису

Якщо запис буде скасовано:
- ❌ Скасування запису (з причиною, якщо вказана)

### Автоматична відправка нагадувань (TODO)
Для автоматичної відправки нагадувань потрібно налаштувати cron job або scheduler:

```python
# Приклад скрипту для відправки нагадувань
# /app/backend/send_reminders.py

import asyncio
from datetime import datetime, timezone, timedelta
from motor.motor_asyncio import AsyncIOMotorClient
import os
from telegram_bot import telegram_bot

async def send_reminders():
    client = AsyncIOMotorClient(os.environ['MONGO_URL'])
    db = client[os.environ['DB_NAME']]
    
    now = datetime.now(timezone.utc)
    
    # Знайти всі підтверджені записи
    bookings = await db.bookings.find({
        "status": "confirmed",
        "reminder_sent": False
    }).to_list(1000)
    
    for booking in bookings:
        # Розрахувати час відправки нагадування
        booking_datetime = datetime.fromisoformat(f"{booking['date']}T{booking['time']}")
        reminder_time = booking_datetime - timedelta(hours=booking['reminder_hours'])
        
        # Якщо час нагадування настав
        if now >= reminder_time and booking.get('telegram_id'):
            await telegram_bot.send_booking_reminder(
                booking['client_name'],
                booking['service_name'],
                booking['date'],
                booking['time'],
                booking['telegram_id'],
                booking['reminder_hours']
            )
            
            # Позначити що нагадування відправлено
            await db.bookings.update_one(
                {"id": booking['id']},
                {"$set": {"reminder_sent": True}}
            )

if __name__ == "__main__":
    asyncio.run(send_reminders())
```

### Налаштування cron (Linux)
```bash

```

## Troubleshooting

### Повідомлення не надсилаються
1. Перевірте токен бота в .env файлі
2. Перевірте що backend перезапущено після додавання токену
3. Перевірте логи backend: `sudo supervisorctl tail -f backend`
4. Переконайтеся що Telegram ID вказано правильно

### Помилка "Invalid token"
- Токен скопійовано неправильно
- Перевірте що немає пробілів до/після токену в .env

### Помилка "Chat not found"
- Telegram ID вказано неправильно
- Якщо використовуєте @username, переконайтеся що в username є @
- Клієнт повинен спочатку написати боту /start

### Бот не відповідає
- Переконайтеся що бот активний у BotFather
- Перевірте що токен правильний
- Спробуйте написати боту /start

## Безпека

1. **Не публікуйте токен бота** в публічних репозиторіях
2. Зберігайте токен тільки в .env файлі
3. Додайте `.env` в `.gitignore`
4. Регулярно перевіряйте логи на підозрілу активність
5. Використовуйте окремого бота для production та development

## Підтримка

При виникненні проблем:
1. Перевірте документацію Telegram Bot API: https://core.telegram.org/bots/api
2. Перевірте логи: `tail -f /var/log/supervisor/backend.err.log`
3. Тестуйте бота через @BotFather commands
